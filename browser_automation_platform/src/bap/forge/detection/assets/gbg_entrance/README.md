# GBG entrance reference sprite

`atlas_diamond.png` — a tight crop of the Guild Battlegrounds entrance building
(`V_IronAge_BattlegroundDiamond`: the golden Atlas-with-globe on a round stone
plaza with steps, columns and a checkered mosaic). Same art on every world.

Used by `bap.forge.action.gbg_entrance` to vision-locate the entrance in a city
screenshot at any zoom/scroll. To (re)make it: screenshot the city, crop just the
building (a little surrounding grass is fine), save here as `atlas_diamond.png`.
